# SBTI 赛博人格测定局 - 实施计划（CloudBase 分支）

> **职责**: 为 AI 开发者提供分步实施指令。严禁包含代码——只写清晰、具体的指令。

---

## 规则（Always 级别）

1. **写任何代码前必须完整阅读** `memory-bank/architecture.md`（包含完整文件结构和云数据库设计）
2. **写任何代码前必须完整阅读** `memory-bank/app-design-document.md`（包含设计意图）
3. **每完成一个重大功能或里程碑后**，必须更新 `memory-bank/architecture.md`
4. **每完成一步后**，必须更新 `memory-bank/progress.md`
5. **Next.js 16 注意**: 写代码前查阅 `node_modules/next/dist/docs/`
6. **静态导出限制**: 本分支使用 `output: "export"`，不能使用 API 路由、服务端动态渲染、中间件等需要 Node.js 运行时的功能
7. **云函数修改后需重新部署**: `tcb fn deploy <name> --dir functions/<name> -e <envId> --force`
